Patch Watch

Every vulnerability we have triaged, sorted by whether it can be measured from outside, and the patch state of Wisconsin's nonfederal .gov websites for each one we measure. Each site gets one ordinary homepage request per snapshot.

How this works. One homepage GET per domain per snapshot, with a declared user agent and published rate limits. Tribal nations' sites are not measured. Per-domain results go only to the principal investigator.

Opt out by emailing jforden@carrollu.edu with your domain. It is removed within 24 hours. The per-run counts behind this page are published as run reports.
