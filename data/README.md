# `data/` — what lives here and why it is gitignored

Everything in this directory except this README is study data or generated output and is
**not** committed to git. Per-domain results never leave this machine (hard rule 7).

## Inputs

| File | Rows | What it is |
| --- | --- | --- |
| `frame_full.csv` | 15,614 | The measurement frame: every nonfederal .gov domain in GSA/CISA's public `current-full.csv`, with type, stratum, organization, city, state. **Contains a `security_contact` column** — held only for a future, not-yet-approved notification experiment, used for nothing in the pilot, and a large part of why this directory is gitignored. |
| `pilot_sample.csv` | 319 | The pilot sample drawn from the frame: 40 per stratum (Interstate contributes all 39 that exist), seeded `random_seed = 20261022`, so the draw is reproducible. |
| `frame_meta.json` | — | Provenance for the frame: source URL, access date `2026-10-22`, download timestamp, `raw_sha256` of the file as fetched, byte count, the seed and stratum floor, and notes on the 1,321 federal-type domains that were dropped and on `security_contact`. |
| `raw/` | — | The unmodified CSV as downloaded, so the frame can be re-derived and checked against the recorded SHA-256. |

Federal-type domains are excluded from the frame entirely: the study measures patching by
nonfederal operators, who are not under the same patch-management regime.

## Generated by runs (safe to delete, costly to lose)

| File | What it is |
| --- | --- |
| `study.db` | The working SQLite database: `domains`, `runs`, `observations`, `request_ledger`, `patch_events`, `meta`. |
| `ledger_<run_id>.csv` | One run's request ledger, exported for reading by a person or attaching to an incident/IRB answer. |
| `request_ledger.csv` | Rolling export of the most recent run's ledger. |
| `*_smoke.db`, `ledger_*_SMOKE*.csv`, `ledger_*_CLEAN*.csv` | Loopback mock validation artifacts. No real traffic, any time. Delete freely. |

## Retention

Keep the database and the ledger exports for five years after publication, on
university-controlled storage. Response bodies are never stored — the crawler reads at
most 64 KB and keeps only headers, a hash, and derived fields — so there is nothing here
that captures a site's content.

If this directory is copied anywhere, copy `frame_meta.json` with it: without the source
URL, access date and `raw_sha256`, the frame is not reproducible and the numbers in a
report cannot be tied back to a public list.
